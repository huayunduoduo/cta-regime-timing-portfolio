日频股债金CTA：复现思路与实际结果

无宏观版本｜510300 / 518880 / 511010｜评价区间2020—2025｜多头/现金研究账户

本研究迁移华泰时序CTA方法，未复现其分钟成交或多空ETF实证数字。配置、ES、波动率控制均为新增研究。2020—2025历史已经被项目反复查看，属于固定规则历史检验，不能称为完全未见的最终样本外。任何指标改善均为本次历史结果，不保证持续。

1. 数据与时间

三只ETF原始OHLC、分红登记/除息/发放日、自建总回报序列；仅这些文件参与计算，宏观完全未读取。历史早期数据用于模型预热；风险配置使用过去126日、风险情景252日。t收盘计算，下一交易日开盘执行。尾部指标为一日95%水平。

2. CTA信号如何生成

30日Kaufman效率比线性确定21—250日AR(1)-GARCH(1,1)窗口和5—20日均线。窗口内MAD修正z分数阈值3.5识别离群价格，Huber线性拟合替代离群点。联合高斯极大似然估计；每个窗口1000次递归标准残差Bootstrap，每次重新估计AR与GARCH。失败复制追加抽样，不能凑足1000则中止。均值/残差条件波动为TSI，使用95%区间；rho的t值来自联合观测Hessian。

连续10日满足趋势条件：TSI区间不含0或|TSI|历史分位数>50%，rho>0，且rho_t>1.5或波动历史分位数<95%。趋势上行且收盘站上自适应均线时买入；震荡RSI14<30买入。做空信号不建立空仓。震荡仓RSI≥50时收盘确认、次日开盘退出（公开补充假设）。

3. 日线账本、止损与分红

趋势仓ATR14，TR在14日窗口5%/95%截断；乘数权益4.5、黄金3、国债1.5。止损盘前确定、全天冻结，多头日最低价严格小于止损时触发；低开穿越按开盘，否则按止损价，另扣滑点。入场日不退出，已持仓日止损后当天不重入。日线不证明真实成交、无法处理盘中动态止损的路径。信号以总回报调整后的OHLC计算，成交使用未复权价格；除息形成应收股息，发放日转现金，持仓固定份额，分红不自动再投资。除息同步调整原始止损价，避免机械误触发。

单边佣金10bp＋单边滑点10bp，买入费用从可用现金扣除；现金收益0。期末按收盘标记、不强制清仓，报告不包含未发生的末日卖出费用。ETF融券约束未建模，故主实验只做多/现金。

4. 配置与风控增量

先分别建立三个CTA资金子账户，再分配子账户权重。等权、过去126日ETF总回报逆波动、10%对角收缩协方差风险平价（ERC）。风险估计采用底层ETF收益而非含空仓的CTA收益，减少空仓期低估风险；属于保守的资产代理风险估计，并非执行止损后的精确组合风险。每月第一个交易日按此前信息调仓，剩余资金留现金。

波动率控制：规模=min(1,8%年化目标/预测年化波动)。ES控制：规模=min(1,1%单日损失预算/95%历史ES)。风险样本252日、联合日期对齐，以当前候选权重构造历史组合损失。两种控制每日审查，规模变化超过2个百分点可触发月内再平衡；风险恢复时按同一公式增仓。无杠杆。两种预算不是风险匹配的最优比较，不能据此证明某种尾部模型优越；应结合平均仓位、收益与回撤综合判断。

配置调仓额另扣20bp单边成本，CTA子账户内部成交已扣20bp；这里将子账户视为可申赎研究载体，调拨另计成本是保守抽象，不是合并ETF订单后的精确成交。换手为买卖名义金额之和/权益、年化；组合内部换手按子账户权重估算。组合再平衡申赎与分红应收并非基金级实盘结算模型。

8. 结果分析与下一步

本次结果不支持ES增量有效。静态股债金等权年化约8.90%、最大回撤11.36%；CTA等权年化约1.98%、最大回撤12.09%。等权ES降仓年化约1.45%、最大回撤11.05%，卡玛低于未降仓，不能把小幅回撤改善当作收益风险优势。逆波动/ERC及其风控版本均亏损；固定预算下这些组合未触发额外降仓，重复净值是实际结果。

分资产看，权益CTA改善了相对买入持有的历史卡玛；黄金CTA大量错过趋势，国债CTA在较低基础收益下承担较高换手和固定费用。逆波动/ERC倾向低波动国债，使亏损子策略权重提高，说明风险分散不等于消除负期望。以上是结果归因线索，未运行成本消融和逐笔反事实，不能将全部损失归因于费用。

先对照单资产买入持有与CTA，再对照静态股债金等权和CTA等权，以区分择时与分散化。随后比较配置方法，最后在同配置下比较none/vol/es。若降仓后回撤缩小但收益同步下降，先检查是否只是风险暴露下降，不直接称为预测增益。黄金/国债单个趋势阶段可能主导整体表现，应查看yearly.csv及各子账户交易。

当前不进行全样本参数优化；未做统计显著性、预算匹配、多成本情景、分红公告完整性独立确认，不作增量有效性定论。未来可以冻结模型后收集新数据；如研究预算优化，应只在训练验证段选预算并使用独立测试段。原始第三方数据不随GitHub源码包再分发。
