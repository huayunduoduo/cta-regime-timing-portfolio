### 讲解流程（约 12–16 分钟）

1. **数据与规则复现（2min）**：四层信号系统——  
   ① 收益三元分解 (μ, ρ, σ)：平均在涨吗 / 方向会延续吗 / 噪声多大；  
   ② ER30 效率比 = 净位移 ÷ 路径长度，走顺用短窗口、走乱用长窗口（21–250 日自适应）；  
   ③ AR(1)-GARCH(1,1)：昨日方向延续 + 波动聚集；  
   ④ TSI = μ/σ，每窗口 1,000 次 Bootstrap 给置信区间。  
   关键词是**确认**：连续多日满足条件才进趋势态——它决定换手率，是后面消融的抓手。
2. **开仓与退出（2min）**：趋势态以 ER 自适应均线（5–20 日）突破方向开仓；震荡态用 RSI(14) 反向（<30 买、>70 平）。  
   **关键改造：研报负向信号开空仓，A 股 ETF 做不了空 → 改成"仅平多、不开空"**——  
   这不是参数微调，是整条空头腿归零的结构改变，后面全部消融由此而来。  
   退出用 ATR 吊灯止损：止损线 = 持仓期最高价 − k×ATR，只上不下；k 按品种 4.5/3.0/1.5（与各资产波幅成反比，实际止损价差同量级）。  
   所有决策收盘做、次日开盘成交。
3. **回测引擎（1.5min）**：四个设计点——复权信号/未复权撮合两套价格；除息应收与分红到账分账；  
   防未来函数两类测试（**历史截断**：截到任意天重跑信号须一致；**未来价格扰动**：改掉未来价格过去信号须不变）；  
   逐笔会计核对误差 < 10⁻¹²（账平在浮点极限）。
4. **24 组消融与分资产定制（2min）**：同一套规则三资产表现差异大，逐项单独开关消融：
   | 资产 | 定制规则                     | 解决的问题                      |
   | -- | ------------------------ | -------------------------- |
   | 股票 | 3 日确认 / 4.5×ATR          | 趋势确认要快，止损空间要宽              |
   | 黄金 | 取消 ρ 门槛 / 10 日确认 / 3×ATR | 黄金趋势慢，自相关门槛滤掉真信号           |
   | 国债 | MA120±0.25% 缓冲 / 5 日确认   | 问题不在方向在换手——30.4 倍降到 0.86 倍 |
   消融锚 2020–2025：累计 43.43%、年化 6.45%、回撤 −5.48%、换手 5.96（旧统一多头版 3.33%/−10.74%/15.81）。  
   **主动降级**：24 选 1 同样有选择偏差，"消融锚"只是给下一阶段配置提供输入的对照基准。
5. **配置与主结果（3min）**：标的 = 510300/511010/518880（股债金各一只，不用期货以免引入基差移仓），  
   共同起点被黄金 ETF 卡在 2013-07-29；区间 = 前 1.4 年预热（60 日波动率/240 日均线/252 日 ES）+  
   2015–2019 学习期选参数 + 2020–2025 评估期；36 组候选 = 3 趋势 × 3 配置 × 2 调仓 × 2 ES 四开关全交叉，事前定死。  
   **权重结构（最防误解的一句）**：平均 17.3% 股票、22.8% 黄金、59.9% 国债——  
   国债波幅约 2%，逆波动一算就顶到 60% 封顶（手算：20/15/2 → 8%/11%/81% → 封顶后 17.1/22.9/60.0）。  
   **所以这个策略实际是"六成国债 + 四成风险资产"，低回撤来自仓位结构，不是择时能力。**  
   评分函数：年化 ÷ max(6%, 回撤) − 0.02×换手——6% 地板防"全现金刷分"。
6. **三个不足**：① 2022 年亏 0.58%，2020–2022 仅 3.31% vs 2023–2025 的 11.88%——成绩依赖利率下行 + 黄金牛市的环境；  
   ② 2020–2025 已被研究者看过，是时间切分不是信息隔离，真验证等 `deployment.json` 冻结后的新数据；  
   ③ 36 选 3 未做多重检验校正，卡玛 1.552 要打折看。
7. **趋势过滤为什么没用**：均线滞后约三个月，只有趋势持续够久才覆盖成本；  
   股票仓位仅 17.3%——长熊跌 30% 组合只亏 5.2%，躲掉三分之二省 3.4%，假信号磨损约 5.4%，净负。  
   **趋势过滤的价值与风险资产仓位成正比**；且样本里没有 2015 式长熊，结论对更长样本不一定成立。
8. **下一步**：补成交额测容量（"能不能做"，现在最大漏洞）→  
   加十年期国债测久期敏感性（"结论稳不稳"，并行版本不替换主方案）→  
   2026 新数据冻结验证（"还灵不灵"，`python portfolio_research.py --data data --end 新日期`）。

## 快速开始

Python 3.10+。阶段 3 入口不依赖 C++ 与缓存，数十秒出结果。**仓库不随包分发行情数据**（授权原因），需自备 `data/etf_daily.csv`、`data/etf_dividend.csv`，字段格式见 [DATA.md](DATA.md)：

```powershell
conda activate cta_research          # 或自建环境
python -m pip install -r requirements.txt
python portfolio_research.py --data data
```

成功后打开 `results/portfolio/portfolio_report.html`。阶段 1/2 的运行方式见各自 README（阶段 1 模型重估需要 g++ 编译器）。

追加新数据：向 `data/etf_daily.csv`、`data/etf_dividend.csv` 追加真实新行情（三 ETF 交易日对齐），然后：

```powershell
python portfolio_research.py --data data --end 2026-05-29 --out results/portfolio_20260529
```
